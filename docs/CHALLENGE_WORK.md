## Why this is a meaningful WebMCP extension

Before ForgeMCP, Terra and Cube were separate human-operated applications. The challenge-period work adds a common browser-native control layer where an agent can discover validated tools, execute real bounded functions, receive structured provenance/verification status, and hand consequential decisions back to the human. The added value is therefore the **human + agent workflow over real data/engine functions**, not a relabeling of the pre-existing Terra or Cube applications.
